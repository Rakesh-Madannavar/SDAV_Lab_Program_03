Exponential Distribution

Industrial Application: Cloud Request Inter-arrival & Microservices Reliability

Industry Problem Statement

An API gateway for an online checkout system receives user HTTP requests modeled by a constant-rate Poisson arrival process. The time elapsed between consecutive incoming requests (inter-arrival time T) follows an Exponential Distribution with average rate λ = 12 requests/min.

Crucial Architectural Distinction:

Inter-arrival time is NOT server response or processing time. Inter-arrival time measures how long the gateway sits waiting between two incoming requests over the internet. Server response time (latency) is how long the backend takes to compute and return a response after receiving it.

Objective: Calculate mean gap, variance, burst probabilities ($P(T \le t)$), survival probabilities ($P(T > t)$), and demonstrate why past wait times give zero memory advantage when forecasting future arrivals.

Memoryless Evaluation: P(T > t₂ | T > t₁)

Tests if waiting t₁ seconds already makes surviving until t₂ any more or less likely than waiting (t₂ - t₁) seconds from scratch.

Automated Unit Conversion

Arrival rate $\lambda$ in requests/min is converted internally to seconds: λ_sec = λ_min / 60, ensuring that math using $t$ in seconds remains mathematically consistent.

Central Limit Theorem (CLT)

Industrial Application: E-Commerce Fulfillment & Warehouse Processing SLA

Industry Problem Statement

In a mega-fulfillment center, individual package picking times are heavily skewed (Uniform or Exponential due to long-tail delays with misplaced items). However, daily shifts process batches of n orders. The Central Limit Theorem states that the average batch fulfillment time X̄ approaches a normal distribution, regardless of the underlying population's original shape.

Objective: Observe how increasing sample size n contracts standard error (σ/√n) and guarantees predictable customer delivery windows (SLAs).

Engineering & AI/ML Takeaway

Even though single picking tasks have extreme variance and positive skewness, groups of 30 orders average out reliably. With Standard Error reduced from 15.00 min down to 2.74 min, logistics managers can confidently promise a 95% SLA delivery window of μ ± 5.37 minutes.
